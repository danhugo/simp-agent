Simp GitHub

You talk. It does the rest.

Simp is a personal agent. Ask in plain words and it plans, writes, and works in your mail, calendar, Drive and GitHub. It asks before doing anything big.

Try it Star on GitHub

Just ask

"Help me plan my week." Simp checks your calendar and mail, writes the plan, and waits for your OK before it saves anything.

Make it yours

Give Simp a name and a way of talking. Describe an outfit and it draws the hat and the bottom. Mix and match from your collection.

It remembers

What you tell Simp and what it learns from your tasks become memories. Next time, it already knows, so you don't repeat yourself.

The app

Run it on your machine

One line starts Simp with a fake model, so you can look around without an API key.

git clone https://github.com/danhugo/simp-agent && cd simp-agent && make dev ARGS=--fake-llm
