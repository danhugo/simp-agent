Hooks and plugins: who is who

A hook (green) is a fixed moment in the run where the session calls out, using a fixed method name. A plugin (blue card) is any object you pass in AgentSession(plugins=[…]); it has a method only for the hooks it cares about. At each hook, the session calls that method on every plugin in the list, in order, and skips a plugin that does not have it.

human approval (ch 08)

HOOKtool_result: change the result before it is saved and sent

At the hook tool_call, the session does:
plugin A has tool_call → call it
plugin B has no tool_call → skip

At the hook context:
plugin A → skip · plugin B → call it

So one plugin can use many hooks, and one hook can reach many plugins.
